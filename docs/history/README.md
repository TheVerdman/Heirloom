# Development history

This directory preserves Heirloom's internal work log, investigations, and milestone notes as provenance. The material records failed experiments, superseded designs, private infrastructure identifiers, and point-in-time results; it is not the current setup guide or a claim that historical validation applies to the present commit.

- `PROGRESS.md` is the long chronological work log.
- `milestones/` contains frozen reviewer notes for selected historical A100 runs.
- `HARD_MODE_INVESTIGATION.md` preserves a prior repository audit.
- `gcp/` preserves dated cloud-validation logs and their private object names.
- `internal/` contains old internal workflow documents.

Use the root `README.md`, `TESTING.md`, and `docs/evidence/` for current reviewer-facing claims.
